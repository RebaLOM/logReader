# LOGER 2: окна, иконка и общее ядро

Окно диагностики открывается с размером 1680×880 и ограничивается рабочей областью
монитора. Таблицы распределяют ширину между колонками, переносят заголовки и
значения; высота строк рассчитывается по отображаемым данным. Длинное имя файла
занимает до двух строк, полный путь доступен в подсказке и исходных данных.
Все шесть позиций DTC сохраняют свои колонки. Поиск и смена файла безопасно
обновляют виртуальные строки даже при многократном изменении их количества.

Параметры экспорта допускают изменение размера и прокрутку содержимого.
Кнопки применения и отмены закреплены. Окна при открытии и смене DPI
ограничиваются рабочей областью монитора. В редакторах DBC/XLSX колонка цвета
резервирует место для полного заголовка. Для строки заголовка окна задаются
цвета текущей темы там, где Windows поддерживает соответствующие атрибуты.
Описание этих атрибутов: [Microsoft Learn](https://learn.microsoft.com/windows/win32/api/dwmapi/ne-dwmapi-dwmwindowattribute).

Новая иконка применяется только к LOGER 2: жёлтая L с импульсом сигнала.
В ICO включены размеры 16, 20, 24, 32, 48, 64, 128 и 256.
Единый ресурс используется в EXE, главном окне, редакторах и сообщениях,
в том числе при открытии диалога без главного окна. Оригинальная иконка
классического интерфейса сохранена. [Исходник и описание генерации](../../logReader.UI/Resources/loger2-icon.md).

Ядро обработки, его тесты и инструменты `Loger.DtcAudit`/`perf` синхронизированы
с `master`. Сохранены новые исправления CSV-времени, ДСТ и XLSX. Дополнительно
устранена потеря последней строки ДСТ при раннем открытии блока из-за допуска
времени: логический конец блока не вычисляется повторно по последнему кадру.
Синхронизация ядра зафиксирована в `master` коммитом `b0b18a6`;
изменений интерфейса в этом коммите нет.

Проверки включают полный набор тестов обработки обеих версий, реальные логи DTC
только из `DST`, сравнение 51 сценария обработки, нативные проверки редакторов,
обе темы, компактные окна, увеличенный текст 125/150%, все шесть слотов и
20 циклов фильтрации. Проверяется SHA-256 исходных логов и совпадение DLL
обработки в двух опубликованных сборках. Увеличение текста является отдельной
проверкой компоновки; физическое переключение мониторов с разным DPI не имитируется.

Артефакты проверки: `artifacts/loger2-ui-review/`.
LOGER 2: `artifacts/loger2-ui-review/app/LOGER.exe`.
Классический интерфейс с тем же ядром: `artifacts/loger2-ui-review/master-app/LOGER.exe`.
