# Поддержка TRC ДСТ без скобки после номера

09.10.2026. Production checkpoint **`566fc24`**, ветка `codex/loger-2-workspace`. По запросу пользователя добавлено чтение строк `N time Rx/Tx ID DLC bytes…`, используемых девятью файлами из `DST_LOGER\DST`. Ранее эти строки ошибочно попадали в ветвь TRC 2.x и отбрасывались.

`TrcLogParser` теперь распознаёт направление в третьем поле как структуру ДСТ без скобки; прежние TRC 1.0–2.1, CAN FD, RTR/error handling сохранены. Индекс 0, стандартные/расширенные ID, дробные миллисекунды и Tx поддерживаются. Заголовок `Время начала записи:` читается и без `;`, включая Windows-1251. Дата сохраняется для ДСТ Time, объединения и разделения по дням. Поиск заголовка останавливается до кадров; неизвестный текст ограничен 64 строками.

Все шесть файлов исправлений bfbea81 сохранены точно; из 55 файлов ядра отличается только `Processing/TrcLogParser.cs`. Проект и зависимости прежние. [Проверка исходников и hashes сборки](evidence/real-data/trc-source-verification.json).

## Проверка реальных файлов

Полный прогон опубликованным ядром: **80 PASS, 0 FAIL, пять входов без подходящего описания CAN**. Все девять ранее ошибочных DST-файлов успешно обработаны. У всех **71 прежде успешных сценариев** совпадают с bfbea81 числа строк, hashes CSV/семантические hashes XLSX и результаты batch. [Полный прогон](evidence/real-data/after-trc-support.json), [строгое сравнение](evidence/real-data/comparison-trc-support.json).

Дополнительный прогон девяти DST-файлов: **27/27 одиночных экспортов PASS** (каждый в CSV, XLSX и CSV ДСТ Коннект) плюс **3/3 пакетных режима PASS**. Это отдельный прогон, частично повторяющий случаи полного набора; счётчики не складываются как число уникальных сценариев. [Результаты всех экспортов](evidence/real-data/dst-all-exports.json).

Строки относятся к данным выбранного предоставленного описания `LOGER\locarusBASE_L450E.dbc`, а не ко всем кадрам шины. ДСТ Коннект формирует строки по блокам, поэтому его счётчик отличается от time-series. Выбор описания по CAN-ID не заменяет сверку физических величин с документацией оборудования.

До и после обоих прогонов SHA-256 **всех 135 входных файлов неизменны**. Источники и прежние результаты пользователя не перезаписывались; новые outputs находятся в игнорируемых `artifacts/perf/real-trc-support-*`. Пять входов без предоставленного соответствующего описания перечислены в [историческом отчёте](real-data.md); их статус не изменился.
