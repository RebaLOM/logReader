## Финальная проверка контракта

`PASS` ниже относится только к указанной проверке. Сохранение исходного обработчика подтверждает перенос функции, но не заменяет испытание всех его ветвей. Native harness проверяет реальные формы и события; UIA управляет отдельным процессом LOGER через Windows UI Automation.

| Возможность | Фактический статус после переноса |
|---|---|
| Один лог или папка | **PASS**: выбор типа источника и Cancel, ручной ввод через UIA, реальная обработка файла и папки. Нативные OpenFileDialog/FolderBrowserDialog — **NOT TESTED** |
| Просмотр лога/папки | **PASS**: окно статистики, число ID/кадров контрольного TRC, поиск. Все форматы через этот экран и закрытие во время сканирования — **NOT TESTED** |
| XLSX/DBC/DBF описания | **PASS**: существующие обработчики связаны; загрузка каждого формата в редактор, DBC в processing pipeline. Изменение файла внешним редактором при открытом приложении — **NOT TESTED** |
| Создание описания XLSX/DBC/DBF | **PASS**: окно выбора всех трёх типов показано; сохранение шаблонов покрыто core tests частично. Полный путь создания через нативный выбор файла — **NOT TESTED** |
| Редактирование описания | **PASS**: показ редакторов, реальные Save/Discard/Cancel и подтверждения удаления на изолированном DBC. Все validation/lock ветви каждого редактора — **NOT TESTED** |
| Фильтрация устройств и параметров | **PASS**: Cancel не меняет модель, OK применяет изменения, «Включить всё» меняет также скрытые поиском параметры. Сверка с неизвестными ID подтверждена core tests; полный фоновой UI-путь сверки — **NOT TESTED** |
| Составные параметры XLSX | **PASS**: формы показаны, core round trip и расчёты выполняются. Полный UI CRUD и dirty close составных параметров — **NOT TESTED** |
| Экспорт и пакетные режимы | **PASS**: кнопка OK сохраняет все три output/batch режима, DST, строку ID; все шесть пунктов фильтра папки доступны и переключаются. Реальная обработка трёх TRC batch-режимов и CSV/XLSX/DST core output покрыта отдельно |
| Путь результата | **PASS**: UIA ValuePattern и контрольный результат; ошибка несуществующего родителя в журнале. Нативный picker, read-only/locked/network paths — **NOT TESTED** |
| Одиночная обработка | **PASS**: запуск настоящим InvokePattern и event route, ожидаемые значения `10;17`, повторное выполнение с одинаковым SHA-256 результата до/после |
| Пакетная обработка | **PASS**: PerInputFile, MergeToSingleFile и SplitTrcByDate через реальный обработчик; отмена и немедленный повторный пакет через UIA; ошибка отдельного файла покрыта core tests |
| Защита исходных файлов | **CODE PRESERVED / NOT TESTED** для всех UI-ветвей совпадающих путей, прав доступа и блокировки; безопасная атомарная запись и сохранение старого результата при ошибке — **PASS** в core tests |
| Фоновая работа, прогресс и отмена | **PASS**: обработка 2 000 000 кадров, отмена, отсутствие частичного результата, восстановление полей, повторная работа; запуск/отмена доступны на странице декодирования и при минимальном окне |
| Закрытие во время операции | **CODE PRESERVED / NOT TESTED**: исходная отмена и `_closeWhenIdle` сохранены; отдельный Yes/No диалог проверен, полный shutdown во время обработки отдельно не испытан |
| Открытие результата | **PASS**: доступность после успеха и сброс после изменения настроек/путей. Запуск внешней программы через shell association — **NOT TESTED** |
