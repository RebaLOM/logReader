# LOGER UI audit workspace

Артефакты двухагентного UI-цикла (`ui-auditor` → `ui-implementer` → verification).

| Path | Purpose |
|------|---------|
| `findings.json` | Общий список замечаний (в git — шаблон/актуальный статус) |
| `screenshots/` | Baseline и after (gitignored) |
| `reports/` | Отчёты циклов (gitignored) |
| `test-data/` | Безопасные тестовые логи/файлы посылок (gitignored) |

Дизайн-источник истины: корневой `DESIGN.md` + `ThemePalette` / AntdUI.
